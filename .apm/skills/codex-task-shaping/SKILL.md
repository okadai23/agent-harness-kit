---
name: codex-task-shaping
description: Use this skill when turning a vague request into a Codex-ready task with goal, context, constraints, done-when criteria, and a verification plan.
---

Produce:

- Goal
- Context
- Constraints
- Done when
- Verification
- Assumptions
- Open questions

Ask concise questions only when ambiguity would make implementation risky or likely wrong.
Otherwise, state assumptions and proceed.

## Gotchas

- Do not turn a small request into a product spec unless the user asked for breadth.
- Do not ask questions that can be answered by reading the repo.
- Put true blockers in Open questions.
